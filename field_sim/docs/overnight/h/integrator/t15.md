## Recommended fixes (owner of ui.css decides; not edited)
1. Diag toasts: move `.dg-toasts` below the run panel or give it a left-of-panel position when `#autorun` is visible. Or drop the toast right offset to avoid the run panel band. Dev-only overlay, so low priority for the robot run.
2. At <=1100 px, hide `#autorun` behind a collapsed state, or position it at `left: calc(var(--left) + 12px)` so it does not sit over the rails and expanded panels.
3. Fix stale comments (`right=288`, `autopanel-left 248`) and remove `#tab-path` rules or the `#pathpanel` code, since there is no path tab.
4. Auto tab at <=900 px: hide the `#plan-flip-lbl` label or let it wrap so the clock stays visible. Verify with a real screenshot first (needs the tab switched).
5. Headless boot timeouts (2 of 4 SwiftShader runs) are environmental, not a layout bug.
