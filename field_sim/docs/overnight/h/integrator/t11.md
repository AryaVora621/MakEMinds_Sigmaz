## Checks
1. **Stuck keys after blur / tab switch: no stuck path found.** keyup always deletes (app.js:600), blur clears (app.js:601), setView clears keys (app.js:1009). Residual, unverified: focus moving into the Pedro iframe should fire parent blur, but this is not tested in a browser.
2. **Modifiers:** keydown with ctrl/meta/alt is ignored for hotkeys and for keys.add (app.js:591). Shift is a real drive key (keys set). Shift+digit produces symbols, so cameras 1-0 do not fire with Shift held. Ctrl+R is not preventDefault'ed, so browser reload still works.
3. **Key repeat: NOT guarded.** No `e.repeat` check anywhere in web/js. Holding G calls flowerArm.toggle() on each repeat (app.js:595, flowerarm.js:47-49), so the arm flips deploy/stow at repeat rate. T/Y (tip), R, I, L and 1-0 also repeat. Holding Space fires shoot() on each repeat keydown (app.js:593); shoot() has no cooldown (app.js:418-431).
4. **Space double-shot (likely, unverified in browser):** keydown calls shoot() (app.js:593) and adds ' ' to keys (app.js:592). The next driveStep sees cmd.shoot with shootHeld false and shoots again (app.js:409). A single tap held over one frame should fire two shots.
5. **Collisions:** the live hotkeys in app.js do not collide with mapKeyboard keys (driver.js:81-88). app.js:595 and 598 use r and i, which are COMMON actions in controls.js:36. controls.js is NOT imported by app.js or index.html (grep finds only OrbitControls), so the remap/presets code is dead in the live app.
6. **Text inputs:** isTyping (app.js:587) ignores TEXTAREA, SELECT, contentEditable and INPUT except checkbox, range, button, radio. Those four are not ignored, so Space on a focused checkbox or button (for example opt-fc, opt-intake) calls shoot() and preventDefault (app.js:593), which likely swallows the native toggle or click. Unverified. Also, `e.key.toLowerCase()` throws if e.key is undefined (app.js:589 and 600).
7. **During an auto run:** driveStep is skipped (app.js:1048), so WASD/QE drive does not act. Still live during auto: Space shoot (app.js:593), R reset (595), T/Y tip, G flower, I intake and cameras. Auto run forces view to 3d (app.js:712), so the 3D hotkeys are live. Whether these corrupt the runner is unverified. F toggle is also frozen because currentCmd is not called (app.js:387-389 skipped), so prevToggle goes stale.
8. **Keyboard speed:** without Shift, keyboard drive is scaled to 0.6 (app.js:386). Not documented in index.html hints.
