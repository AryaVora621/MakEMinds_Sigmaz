# t02: Run-in-sim from the 3D view (audit, read-only)

Scope: read web/js/app.js, web/js/autoui.js, web/index.html, web/js/autos.js. No files edited, no servers started, no tests run. Everything below is from reading code (evidence = file:line).

## (1) Is autoPlanner created at page load?
YES, at page load, not lazily.
- app.js:690 `const autoPlanner = createAutoPlanner({...})` runs during app.js module init. Its DOM targets (`#autopanel-left`, `#autopanel-right`, `#timeline`) are plain index.html elements (index.html:186-188). Nothing waits for the Auto tab.
- autoui.js:947 `refresh()` renders the left, right and timeline DOM at construction time, even while `#autopanel` is `display:none` (ui.css:188).
- autoui.js:935-939 reopens the most recently saved auto from storage (`libraryList(st)[0]`), so the planner has a real auto before any tab opens.
- autoui.js:114 `let auto = newAuto()` is the fallback when storage is empty.
- The planner's CSS is injected at construction (autoui.js:106-109).
- Consequence: "Auto planner tab never opened" is NOT a blocker for running. The missing piece is a control.

## (2) Is there any control in the 3D view that can start a run?
NO. Nothing in the 3D view starts a run.
- Run entry points are all in planner DOM: autoui.js:559 (`run-top`, planner header), autoui.js:763 (`run`, planner head), and the Play/Pause button in the timeline (autoui.js:804-805, `runBtns.pause`). That is `#autopanel` and `#timeline`, which are hidden outside the Auto tab (ui.css:188-189, 196).
- The 3D run panel `#autorun` (index.html:173-183) only offers Pause, Stop, Restart and Edit. It has no Run button.
- It is hidden unless `AR.show` is true (app.js:717-718). `AR.show` is set only on the transition into `running` (app.js:712), so it is never set from the 3D side.
- `ar-close` (app.js:738) sets `AR.show=false`, so after closing, the panel does not come back without a run.
- There is no chooser for which saved auto to run in the 3D view. The planner library list (autos.js:355 `libraryList`) is only used inside the planner.
- Keyboard: the 3D hotkeys (app.js:588-598) have no run key. Space is shoot (app.js:593).
- Gap found, app.js:726: `ar-pause` already reads "Run" when the runner is idle, and its onclick calls `autoPlanner.pause()`. Per autoui.js:846, `pause()` with no runner or a finished/errored runner calls `run()`. So the run path exists, but the panel is never shown.

## (3) What happens with no auto loaded?
An auto is always loaded, so the "no auto" case cannot occur. Details:
- The planner always holds an auto object: either the last saved library item (autoui.js:935-939) or `newAuto()` (autoui.js:114, autos.js:73-81, default root empty, matchSeconds 30).
- An empty root shows the hint "Empty auto. Click or drag a command..." (autoui.js:576).
- `run()` (autoui.js:834) first runs `issues()` (autoui.js:701). Only `level === 'error'` entries block the run. Whether `validateAuto` flags an empty root as an error is UNVERIFIED (I did not read the validator). If it does not, the runner should finish at once (state `done`, UNVERIFIED).
- Edge case, app.js:725: `updateAutoPanel` uses `r.time` and `r.errors` without a null check. Once the panel is shown with no runner, this throws. Today it is guarded only by `!!r` at app.js:717.
- Note: `autoPlanner.runner` is `null` until the first run (autoui.js:115, 830). So `show = AR.show && S.view==='3d' && !!r` (app.js:717) is false on a fresh load even if AR.show is forced true. The patch must handle this.

1. index.html, inside `#leftpanel` (index.html:57, position inside the panel UNVERIFIED, I did not read it), add:

2. app.js, after app.js:738 (the `ar-close` line), add:
```js
$('ar-run3d').onclick = () => { AR.show = true; if (autoActive()) return; resetAllState(); autoPlanner.run(); };
```
`autoPlanner.run` is exported (autoui.js:943). `resetAllState()` mirrors `ar-restart` (app.js:737). `autoRunTick` (app.js:712) then switches to the 3D view and shows the panel.
3. app.js:717-718 and 722-725, so the panel can show before any runner exists:
```js
const r = autoPlanner.runner, p = $('autorun'), st = r ? r.state : 'idle', show = AR.show && S.view === '3d';
...
const rt = r ? r.time : 0, rErr = r ? r.errors : [];
$('ar-fill').style.width = Math.min(100, st === 'done' ? 100 : (rt / Math.max(total, 0.1)) * 100).toFixed(1) + '%';
$('ar-time').textContent = rt.toFixed(1) + ' s / ' + total.toFixed(1) + ' s';
$('ar-src').textContent = st === 'error' ? 'Error: ' + (rErr.slice(-1)[0] || 'unknown') : ...;
```
(Change `r.time` and `r.errors` the same way in the `ar-src` line. Keep the rest.)
