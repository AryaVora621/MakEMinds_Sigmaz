## 4. Manual step left for the user
1. In Onshape, open the new element (`/e/3ac0308e...`) and right-click its tab > Export > GLTF (GLB preferred).
   Turn Compress/Draco OFF. Units: any (loader auto-detects). Source: `web/data/MODEL_README.md` lines 8-14.
2. Save as `web/data/robot.glb`, OR run
   `.venv\Scripts\python.exe tools\import_robot_cad.py <exported file>` (writes `web/data/robot.glb` by default).
3. Onshape is Z-up: the call must pass `orientation: { upAxis: 'Z', forwardAxis: '+X' }` (unverified which default
   Onshape's glTF uses; check by looking). `docs/overnight/robot-model.md` lines 41-50 describe the app.js patch
   (owned by another worker, not applied here).
4. Then open the sim and check the CAD is placed, sized and facing the right way (headless screenshot not done).
