## Trace: how balls leave a tipped hive
1. The tip animation runs in hivecycle.js `HiveDynamics.step()` (hivecycle.js:225). app.js drives it every frame at app.js:1061 (`hiveDyn[a].step(dt); h.shown = hiveDyn[a].angleDeg`).
2. app.js:451 passes the live angle to the physics world: `world.setHiveAngles({red: hive.red.shown, blue: hive.blue.shown})`.
3. app.js:452 calls `world.step(dt)`, once per frame, from `updateBalls` (app.js:447, called at app.js:1064, after the hive step).
4. balls.js:491 calls `_releaseDrained()` at the end of every physics step when `dropOnTip` is true. The default is true (balls.js:213, `env.dropOnTip !== false`). app.js:293 does not override it.
5. balls.js:397-414 `_releaseDrained()`: for each cell whose floor now slopes toward its opening (`uz >= DROP_SLOPE`, 0.17, balls.js:201), every stored `scored` ball in that cell becomes `free` at its current position with the hive's tangential velocity. Gravity and the hive collider then roll it out.
6. Result: the physics side is wired for every frame and for both tip paths (natural and animated). Drop-out does not need a model tip. It fires as the tilt crosses the threshold.

## Wiring gaps in app.js (owned by integrator)
- GAP 1 (model ghosts, app.js:293): `world.onRelease` and `world.onRecycle` are never set. balls.js:410 and balls.js:438 call them, and the hivecycle model still holds a record for each physically released ball. Only `forgetBall` (hivecycle.js:245) removes those records, and nothing calls it. Effect: `cycleStats()` and the HUD keep counting balls that are already on the floor until a natural tip settles and filters the lowered cell (hivecycle.js:215-218).
  Fix (one line after app.js:293): `world.onRelease = world.onRecycle = (b, alliance, cell) => hiveDyn[alliance].forgetBall(cell, 1);`
  This is the patch already requested in docs/overnight/hive-physics.md:43, and it has not been applied.
- GAP 2 (manual and remote tips skip the model tip, app.js:518 and app.js:636): both call `setState(next, true)`, which is animated with natural=false (hivecycle.js:236-241). That path never calls `onTip`, so `scorer.onTip` (app.js:443) and the tip count are not updated. The lowered cell's records are removed only on a natural tip. GAP 1's hook fixes the ball-count side. The tip-count side still needs a decision (unverified whether it matters for scoring).
- Not a gap: `resetField` (app.js:548-552) and `resetHiveDynamics` (app.js:566-573) reset hives and balls together. Reset does not trigger drop-out, and it should not.
