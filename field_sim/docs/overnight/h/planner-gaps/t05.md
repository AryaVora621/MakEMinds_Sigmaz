## Feasibility of a minimal honest optimizer
- "Report estimated time": already done by the time chip. A second card would duplicate it.
- "Shorten" by removing redundant points: not honest. `followSim` (pathing.js:338-357) limits speed only by zone vmax, `segment.speed`, and accel. It has no corner or curvature limit, so deleting collinear anchors leaves the simulated time unchanged unless segment speeds or zones differ. Merging segments also shifts heading mode (linear/constant/tangent), rotation targets, callbacks (t per segment), and zone indices. The button would change the file and not the time.
- A real time-optimal profile needs robot-measured accel/decel, turn limits and Pedro constraints. Those are not in the repo and must not be invented (OVERNIGHT_RULES: no invented constants).
- Decision: feasibility = NO for an honest optimizer. Recommendation = REMOVE the card. The time chip stays.
