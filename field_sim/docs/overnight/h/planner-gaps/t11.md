## 4. Pointer input on the planner canvas
Input path: `mapCv` (`#map2d`) gets `pointerdown` / `pointermove` (app.js ~995-999). `pointerup` is on `window`. Both go to `pathEditor.pointer(...)` in pathui.js when `pathEditor.editing` is true (true on the whole Auto tab). With no path open, `overviewPointer` only opens a path on click (pathui.js ~349). It does not move the robot.

Working snippet (CDP `Input.dispatchMouseEvent`, so the events are trusted):
```js
const send = (method, params = {}) => new Promise(ok => { const i = ++id; waiters.set(i, ok); ws.send(JSON.stringify({ id: i, method, params })); });
const mouse = (type, x, y, extra = {}) => send('Input.dispatchMouseEvent', { type, x, y, button: 'left', clickCount: 1, ...extra });
// canvas rect from evalJs("document.getElementById('map2d').getBoundingClientRect()")
await mouse('mouseMoved', sx, sy);
await mouse('mousePressed', sx, sy, { buttons: 1 });
for (let i = 1; i <= 10; i++) await mouse('mouseMoved', sx + i * 8, sy + i * 4, { buttons: 1 });
await mouse('mouseReleased', sx + 80, sy + 40, { buttons: 0 });
```
Full script: `C:/Users/Jindal/AppData/Local/Temp/claude/1bf884c3629a4194/cab1052d-b484-449d-8151-8eddbe3da6ad/scratchpad/cdp_planner.mjs` (run with `SP=<scratchpad> node cdp_planner.mjs`, ~5 s).
- Recorder: a listener on `map2d` pushes `[type, x, y, isTrusted]` into `window.__ptr`. Verified result: 13 events (1 move, down, 10 moves, up) all `isTrusted: true`.
- Synthetic alternative (untrusted, JS handlers only): `c.dispatchEvent(new PointerEvent('pointerdown', {clientX, clientY, button: 0, bubbles: true}))`. Use it only if CDP is unavailable. It does not trigger default browser behaviour.
- Touch: `Input.dispatchTouchEvent` with `touchStart` / `touchMove` / `touchEnd`, same coordinates. NOT verified here.
