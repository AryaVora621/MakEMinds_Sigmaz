- Waypoints section: `h += sec('waypoints', 'pin', 'Waypoints', ...)` (line 790). Icon id = `pin`.

- Hard-coded `#23232a` hole does not follow theme tokens (THEME.surface is `#23232a`, so it matches dark mode only). Light-mode mismatch is unverified.

## Finding 3: duplicates (identical SVG inner strings)
- `del` = `delete` = `delseg` = `pdel` = `M5 7h14M10 7V4h4v3M7 7l1 13h8l1-13` (trash can). Four ids, one shape. Fine for same action, but `delete` (tool), `del` (path row), `delseg` (split row), `pdel` (path menu) all look identical.
- `copy` = `pdup` = rect+corner-path (duplicate). Same visual for "copy Java" and "duplicate path": ambiguous.
- `cbadd` = `pnew` = `plus` = `M12 5v14M5 12h14`. Three ids, one shape; "add event", "new path", and "+" add are the same glyph.
- `download` = `importpp` = `M12 4v12M7 11l5 5 5-5M5 20h14` (arrow-down into tray). "Download .java" and "Import .pp" look identical. Real lookalike bug: import and download point the same way.
- `save` vs `load`: different shapes, fine.

## Finding 4: lookalikes (not identical, easy to confuse)
- `pin` (Waypoints) vs `marker` (Event Markers): same teardrop outline, both filled. Differ only by the inner hole (circle) vs check mark. At 18px they read as the same icon.
- `reset` vs `rot`: both circular arrows, arrowhead on opposite corners. Reset is the playback "reset to start"; rot is rotation targets.
- `toggle` vs `start`: both right-pointing triangles/arrows.

## Proposed replacement for Waypoints (24x24, stroke, matches others)
Three nodes (ends + middle) joined by a polyline. Unused id in ICONS, so it is safe to add as a new key (name suggested: `waypoints`). Change line 790 from `'pin'` to `'waypoints'`.

Exact inner string to paste into ICONS:

```
waypoints: '<polyline points="4 18 12 6 20 18"/><circle cx="4" cy="18" r="2"/><circle cx="12" cy="6" r="2"/><circle cx="20" cy="18" r="2"/>',
```

Rendering notes: `ico()` wraps with fill none, stroke currentColor, stroke-width 2, round caps and joins (line 75), so the polyline and circle outlines inherit the house style. Circles fit the 24 box (x 2-22, y 4-20). Rendering check not done (no screenshot; read-only task).
