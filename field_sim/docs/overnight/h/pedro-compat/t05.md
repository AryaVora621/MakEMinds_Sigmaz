## Concrete differences
1. Pose/path library: visualizer uses com.pedropathing.api.Paths / PoseFactory / math.Pose / paths.Path (Path return type). autoexport uses geometry.Pose, geometry.BezierLine/BezierCurve and paths.PathChain. The two target different Pedro API generations; the golden files cannot validate autoexport's types.
2. Follower access: visualizer owns `Follower follower` in the OpMode and calls `follow(follower, ...)`. autoexport calls `robot.auto.getFollower()` and has no follower field.
3. Imports: visualizer imports Scheduler, schedule, Commands.*, Groups.sequential, PedroCommands.follow explicitly. autoexport imports only `PedroCommands.*` and uses fully qualified `com.pedropathing.ivy.Scheduler`. Whether PedroCommands re-exports sequential/instant/waitUntil is unverified; the visualizer goldens show sequential comes from Groups and commands from Commands.
4. Wait: visualizer uses `waitMs(ms)`; autoexport uses `waitSeconds(s)` marked UNVERIFIED. Visualizer is the only verified name in the local sources.
5. Scheduler lifecycle: visualizer calls Scheduler.reset() before building; autoexport never resets.
6. Root call: visualizer uses `schedule(autoRoutine())` (static import) after waitForStart; autoexport uses the qualified call, same placement. Equivalent order.
7. Routine method: visualizer emits `public Command autoRoutine()` returning `sequential(...)`. autoexport emits no autoRoutine method in ivy mode; the expression is inlined into startRoutine().
8. Command steps: visualizer emits raw command expressions (sample: none in goldens). autoexport wraps commands in `instant(() -> { robot... })`, and TIMED commands become instant() with TODO. No golden coverage.
9. Completion: visualizer ends by polling Scheduler.execute() only; autoexport declares `finished` but never sets it in ivy mode (rootRun = 'finished' is never assigned on that path). Likely dead flag; verify.
10. Header/lifecycle: autoexport adds robot.stop() in finally and telemetry "finished"; visualizer has no finally block.
11. Statemachine path: autoexport has no visualizer equivalent to compare; the visualizer only emits the Ivy form. Statemachine is therefore unverified against any official sample.
