## Mismatches and open items (for the exporter owner)
1. `waitSeconds` and `waitUntil` have no confirmed Ivy name. Keep the UNVERIFIED tag. A safe interim option is `instant` plus a `Command.build()` with a timer in `done()`. This is an inference, not a verified API.
2. The Scheduler class and its `schedule`/`execute` methods are unconfirmed. The Scheduling page 404'd and the GitHub repo 404'd. Next step: a human must open the Ivy source or javap the 1.1.1 jar (download once from Maven Central into a scratch directory, then javap).
3. `follow()` parameter type: a `Path` vs `PathChain` question stays open, as the exporter already notes.
4. Pedro 2.x chain callbacks are unrelated to Ivy. Do not conflate them.
5. The WebSearch hit "NextFTC" is a different Kotlin framework. It was not used for any name in this table.

## Result
Confirmed: group names, `follow`, `instant`, `PedroCommands` import, and the Gradle coordinate. Unconfirmed: `waitSeconds`, `waitUntil`, Scheduler class and methods. The exporter should keep those tagged UNVERIFIED.
