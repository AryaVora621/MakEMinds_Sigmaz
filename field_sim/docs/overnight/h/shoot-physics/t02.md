## Mismatches against the header
1. Manual header (lines 15-17) says these are hard and block: flywheel below MIN_SPIN_RPM, ball path blocked within EXIT_BLOCK_IN, robot out of field. Code: with strict false these become warn and the shot is allowed (finish(), line 325, since only NO_AMMO / WRONG_MODE_PARAM / ILLEGAL_ZONE are in HARD). The header's physics-only paragraph (line 20) says the opposite. The file contradicts itself for manual + strict false.
2. Assist header (lines 11-13) says "every physics rule is still enforced" with no strict qualifier. Code with strict false demotes all of them (rpm, hood, turret, trajectory, field, behind) to warn. Either the header needs "strict" added or assist needs its own HARD subset.
3. Undocumented: hintFor() runs before demotion (line 323), so an allowed non-strict shot still returns a block-style hint such as "Move closer than N in". The summary reads "Will fire, likely to miss", but the hint text is not documented as possibly present on an allowed shot.
