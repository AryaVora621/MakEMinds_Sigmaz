## Q1: pickEquivalentTurretAngle wrap correctness
- Valid-k math is correct: kLo/kHi give every k with target+360k in [min,max]. Tolerance 1e-9 in k units is inclusive at the boundary.
- Target +-180 with limits -180..180: returns the nearer equivalent. Probes: (180, cur 170) -> 180; (-180, cur 170) -> 180; tie (180, cur 0) -> -180 (ties go to lower k, deterministic).
- Asymmetric limits: correct. Example (170, -170, -270, 270) -> -190 and test passes.
- No valid equivalent: returns null (narrow 0..100 with target 200 -> null; min>max -> null). Correct.
- Cur far outside the window: fallback to kLo/kHi picks the nearer bound candidate. Probe (10, cur 700) -> 10 is correct.
- BUG-LIKE GAP (low risk): NaN limits are not rejected. pickEquivalentTurretAngle(10, 0, NaN, 180) returns 10 because kLo is NaN, the window loop is empty, and the fallback loop compares a candidate built from a NaN bound-derived k. Returned value is not validated against limits. Fix: `if (![minDeg,maxDeg,targetDeg].every(Number.isFinite) ) return null` at the top.
- Returned angle can sit up to ~3.6e-7 deg outside [min,max] because of the 1e-9 tolerance. Harmless, since ShooterPlant clamps.

## Q2: ShooterPlant.step stability
- Turret: move is capped at |err| (no overshoot). Monotone contraction for any dt >= 0. dt=0.1: turret 0 -> 54 -> 90 -> 90 (probe). Stable, no oscillation at large dt.
- Hood: rate-limited step toward target, no overshoot. Stable.
- Flywheel: a = 1 - exp(-dt/tau) is in [0,1] for dt >= 0. Stable for large dt. Dip recovery uses a smaller tau; still in [0,1].
- dt=0: turret, hood and rpm all hold (probe: turret 0, rpm 3000). Correct. Note `_dipT` is undefined before first kick, but `undefined > 0` is false, so no crash.
- NOT GUARDED: negative dt. Probe: dt=-0.1 moves turret to -54 (away from 90) and rpm 3000 -> 2008 (away from 6000). No assert, no early return. Low risk if callers never pass negative dt; recommend `if (!(dt > 0)) return` or clamp dt to >= 0.
- ShooterPlant does not wrap; a turret target outside limits saturates silently at the limit. Callers rely on modeCommand pre-wrapping, which is correct.

## Q3: modeCommand null solution and prev
- auto + null/!ok solution: returns prev's turret/hood/rpm with label 'no solution'. Correct. With prev null it returns nulls, and ShooterPlant skips null fields. Correct.
- BUG: missing or null sol.rpm in auto mode. clamp(undefined) gives NaN (returned rpm NaN); clamp(null) gives 0 (probe: rpm 0, not hold). A null rpm silently commands the flywheel to stop. Fix: treat non-finite sol.rpm as hold (prev.rpm) or as no-solution.
- Caller contract issue: app.js:365 passes S_AIM.lastCmd (the last COMMAND) as prev, not the plant's actual turret angle. modeCommand uses prev.turretDeg as `cur` to choose the wrap. The plant lags commands, so the chosen equivalent can be based on a stale angle. Also app.js:350 resets lastCmd to null on mode change, so cur falls back to 0 instead of the real turret angle. Recommend passing the plant's actual state (plant.state.turretDeg) as cur.
- `turretCableWrap: false` in DEFAULT_PLANT is never read anywhere (grep of web/). Dead flag; either implement cable-wrap logic or remove it.

## Q4: ManualAim (secondary)
- Snap edge detection consumes the edge even when sol is not ok (_prevSnap is set regardless). Pressing X with no solution requires a release and re-press later. Minor UX note, not a crash.
- Snap with an unreachable turret (pickEquivalent null) still snaps hood and rpm, and leaves the turret unchanged. Partial snap is silent. Low risk; consider returning a flag.
- ManualAim default turret/hood limits are copied from DEFAULT_PLANT, not from the plantSpec in app.js. If the spec ever differs, the manual clamp and the plant clamp disagree.

## Test coverage gaps (tests_js/aimcontrol.test.mjs)
- No test for dt=0 or dt<0 on ShooterPlant.
- No test for NaN limits in pickEquivalentTurretAngle.

## Verdict
Wrap selection and rate-limited plant are sound for normal inputs (20/20 tests pass; probes agree). Fix before relying on it: (1) auto rpm null/missing commands 0 or NaN, (2) prev should be the actual plant turret angle, (3) NaN-limit guard, (4) negative-dt guard. No code was edited.
