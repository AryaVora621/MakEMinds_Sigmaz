## Integrator (_substep, lines 492-540)
- Drag, airborne only (b.z > r + 0.05), line 500-503: f = 1/(1 + k|v|h). Applied to velocity before the position update.
- Position and velocity update, line 504: x += vx*h; z += vz*h - 0.5*G*h^2; vz -= G*h. This is exact for constant gravity. Gravity is not mass-dependent.
- Speed clamp, line 506.
- Floor and walls, lines 520-527. Hive and robot, lines 510, 517, 530.
- Sleep, lines 535-538: needs b._c (a contact this substep) and |v| < 1.5 in/s for 0.25 s. Sleeping balls skip integration (498), hive sweep (510), and static collision (518).

## Plausibility
- Gravity: correct for inches.
- Size: the task says a ~5 in ball. The code uses 2.78 in (pollen) and 3.60 in (nectar), citing manual TU06 Sec 9.8 (lines 27-28). A 5 in ball does not appear anywhere in the code. This is a mismatch to resolve with the user or the manual. The manual was not checked here. Source links are cited in comments, not fetched.
- Bounce threshold: restSpeed = 5 in/s is about a 0.03 in drop height. So any real drop bounces. At rest the per-substep gravity is about 0.8 in/s, so no chatter. Fine.
- Restitution: 0.45 on floor gives a rebound height of 0.2 of drop height, and 0.7 ball-ball gives about 0.5. Whether a foam ball matches these is UNVERIFIED. No measurement exists (TODO at line 54).
- Drag: 0.0004 1/in is a tuning value, not a physical one. Flag this.
- Rolling: friction is applied as a tangential speed cut (line 170). The ball has no spin state, so the "rolling" is really sliding with a fixed decel. Acceptable as an approximation, not a rolling model.

## Sleep and wake (freeze-mid-air risk)
Wake paths:
- _wake (361-369): wakes the ball and the sleepers above it in contact. Does not wake walls.
- _wakeAbove (372-378): on removal, hold, or capture. Fine.
- _wakeNear (484-490): wakes sleepers within hv.R of the pivot in the y-z plane (cylinder). Called from step() at line 434 (teleport >20 deg) and line 435 (|dd| > 0.02 deg per call).
- _robotCollide (674): wakes on robot proximity.
- _pair (619-620): wakes only when approach speed > 3 in/s.

Findings:
1. Frame-rate-dependent wake gate (line 435). The threshold is 0.02 deg per call to step(dt), not per second. Walls at 60 Hz wake only above 1.2 deg/s. At 240 Hz (stepFixed) the threshold is 4.8 deg/s. Slower wall motion does not wake sleepers. A ball resting on a receding wall stays asleep and floats.
2. Sleepers are invisible to the hive. Lines 510 and 518 skip sleeping balls, so a wall moving through a sleeping ball passes through it until a wake happens. The only wake is line 435, so finding 1 applies here too.
3. Real exposure is small for the app's own motion. hivecycle.js:55-56 sets animationDuration 0.6 s and a 60 deg swing (-30 to +30). Smoothstep speed is 600*u*(1-u) deg/s. At 60 Hz the first frame is about 16 deg/s, so the wake fires on frame 1. Below-threshold windows are about 1 ms at each end. Risk is concentrated in slow or ramped setHiveAngles calls, very small dt, and any test that ramps the hive slowly.
4. stepFixed is not used by the app. app.js:452 calls world.step(dt) with frame dt. The fixed-step claims in the header (balls.js:200, 470-473) do not apply to the app path.
5. Sleep decision uses absolute ball velocity (line 535), not velocity relative to the wall. A ball riding a wall at under 1.5 in/s may sleep. The wall-motion wake (finding 1) then carries the fix. Acceptable, but depends on finding 1.
6. Dead code at line 618 (`if (a.sleeping && -vn >= 0) {}`). No effect.
7. Hive teleport branch (434) sets hv.omega = 0 and wakes, but skips the sweep. A ball can end up inside the wall after a jump greater than 20 deg. Not a freeze, but a penetration.

## Suggested fix (not applied, file not owned)
- Replace the line 435 gate with a per-call "any change" test (dd != 0), or with a speed test in deg/s that does not depend on dt. This removes finding 1 and 2.
- Add a test: rest a ball on the hive wall, ramp the hive at 0.5 deg/s and at 1 deg/s with step(1/240) and step(1/60), and assert the ball is awake and falling by the time the wall is 2 in away.
