# t06: hive-to-balls seam audit (read-only)

Ran grep and sed only. No tests, no sim run, no edits. Files: web/js/hivecycle.js (HD), web/js/balls.js (BW), web/js/app.js, web/js/matchrules.js, web/js/hivetip_model.js, web/data/scene.json.

## Data flow
- **Ball objects**: BW owns them. `this.balls`; captured balls get `state='scored'`, `hive`, `cell`, `_slot` and are re-placed every step (balls.js:465, `_placeScored` 390).
- **Capture**: `_hiveCapture` (balls.js:757-770) -> `_capture` (404-420) -> `_pending`. In `step()`: `recordHiveBall` (466), then `onCapture` (467).
- **Only link BW to HD**: app.js:433-435 `hiveDyn[a].addScoredBall(cell, [x,y,z], kind)`.
- **HD store**: `this.scored` of records `{cell,type,counts,local}`, no ball id (hivecycle.js:116-123).
- **Tip decision (HD only)**: `addScoredBall` (179-189) -> `_shouldTip` (147-157) -> `shouldTip` in hivetip_model.js:94.
- **Hive angle (HD owns)**: `step` (224-233). app.js:1060-1062 writes `hive[a].shown`. app.js:451 pushes it to `world.setHiveAngles` (balls.js:349), same frame.
- **Tips**: natural via `_settleAt` -> `onTip` (hivecycle.js:220 -> app.js:441-445). Manual `tip()` (app.js:514-518) and remote `poll()` (app.js:636) call `setState(n,true)`.
- **Score**: matchrules.js:89-93 `onTip`, 144-160 `finalize`. Fed by app.js:443 and app.js:1038 (`cycleStats().upCellCount`).
- **HUD**: app.js:1116-1126 reads `d.scored` counts flags.

## Duplicated state
1. BW scored balls (physical, shrinks on recycle, balls.js:410-413).
2. HD `scored[]` (monotone except `releaseOnTip`; not trimmed on recycle).
3. `HIVE_BALL_COUNTS` (balls.js:131-146). Monotone, cleared at 254. Only writer is 466. No web/js reader; `hiveBallCounts`/`tipReady` used only in tests_js/ballkinds_*.test.mjs. Dead for the app.
4. app.js `hive[a].state/.target/.shown` (135-142) vs HD `state/theta`. app.js sets `hive[a].state` before the move settles (518, 636), so aim marks and aimTarget (219-224) flip during the 0.6 s move while balls still count into the old cell.
5. `HIVE_HUD_POLLEN_THRESHOLD = 8` duplicates `HIVE_TIP.threshold` (fallback only).

## Findings, by risk
**F1. Starting nectar may count toward a tip (likely, untested).** hivecycle.js:98 stores 3 uncounted nectar per hive (decision at 36-38). scene.json also has 3 real `nectar_red` (red audience cell) and 3 `nectar_blue` (blue far cell), start=true. They are sleeping, so `_hiveCapture` skips them (balls.js:760). But `_wakeNear` (434-435) wakes them on hive motion, and a woken one resting for captureRest (0.15 s, 767) is captured. `addScoredBall` then sets `counts=true` (hivecycle.js:180), so it counts 1.75 and can tip early. Result: two records per preload nectar. Test: wake/capture a preload, check `cycleStats().upNectar`.

**F2. Balls cannot drop out of the hive.** BW re-places scored balls every step (465). Only `_recycleFired` (320) and reset remove them. `release()` (338) has no caller. `releaseOnTip` (hivecycle.js:216-219) filters only HD records, so with it on the balls stay visible but uncounted. Default is false (app.js:286). A real release path is needed for the user's "balls drop out" request.

**F3. End-of-match hive points use the tip-progress counter.** `upCellCount` (hivecycle.js:252) = `counts`-flagged balls. `counts` clears at every tip (213) and excludes starting nectar. matchrules.js:144-149 awards 2 per ball in the UP cell at the end. After any tip, balls already in the new up cell are not counted, so end points are wrong. Should count BW balls with `state==='scored' && cell===up`.

**F4. Manual and remote tips score nothing.** `setState(n,true)` passes `natural=false` (hivecycle.js:240), so `onTip` never fires (214-220). app.js:514-518 and 636 skip `scorer.onTip` (443). Visible tips are not counted in tipsTeleop/tipsAuto or the 20-point score. Maybe intended for test buttons; the remote path is not labelled.

**F5. Recycle drift (low).** `_capture` (410-413) splices the oldest ball from a full cell, HD not told. `scoredInCell`, `scoredTotal`, `torqueBalls`, and `HIVE_BALL_COUNTS` keep it. Needs more balls than cell capacity; unverified.

**F6. Kind derived two ways (latent).** app.js:434 regex on type; balls.js:121 `kindOf` prefers `ball.kind`. scene.json balls have no `kind`, so no mismatch today.

**F7. Unused threshold.** `HIVE_PARAMS.ballsToTip` = 8 (hivecycle.js:53) is reported by `cycleStats` (254) but ignored in default `mode:'weight'`.

## Checked, consistent
- Angle frames: HD `_store` uses absolute theta (118, 203); BW uses `delta = angle - cad` (391). Same rotation. `local` feeds only `torqueBalls`.
- Frame order: step (app.js:1061) then setHiveAngles (451) in one frame.
- balls.js imports `shouldTip` (92) but uses it only in dead `tipReady` (146).

## Desync summary
Two physical truths (BW balls rendered, HD records counted) joined only by `onCapture`. Tip progress, end points and HUD use three counters (`counts`, `scored`, `upCellCount`).
