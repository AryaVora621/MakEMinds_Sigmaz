## Signatures
- hiveTipVisual({t, tipStartT, fromDeg, toDeg, tipDurationS}) -> {angleDeg, progress, releasing}
- dropSchedule({nBalls, tipDurationS, releaseStartFrac, staggerS}) -> number[] (seconds after tip start, ascending)
- dampedEase(u) -> number, u in [0,1], exported helper.
- Semantics: t before tipStartT gives (fromDeg, 0, false). Inside the window gives releasing = true. At or after the end gives (toDeg, 1, false). tipDurationS <= 0 snaps to the end state at t >= tipStartT.

## Reference implementation (run in node; file is in the scratchpad, not in the project)
```js
const DAMP_K = 6; // ASSUMED cosmetic; TODO tune
const NORM = 1 - (1 + DAMP_K) * Math.exp(-DAMP_K);
export function dampedEase(u) {
  return (1 - (1 + DAMP_K * u) * Math.exp(-DAMP_K * u)) / NORM;
}
export function hiveTipVisual({ t, tipStartT, fromDeg, toDeg, tipDurationS }) {
  const el = t - tipStartT;
  if (!(tipDurationS > 0)) {
    const done = el >= 0;
    return { angleDeg: done ? toDeg : fromDeg, progress: done ? 1 : 0, releasing: false };
  }
  if (el < 0) return { angleDeg: fromDeg, progress: 0, releasing: false };
  if (el >= tipDurationS) return { angleDeg: toDeg, progress: 1, releasing: false };
  const u = el / tipDurationS;
  return { angleDeg: fromDeg + (toDeg - fromDeg) * dampedEase(u), progress: u, releasing: true };
}
export function dropSchedule({ nBalls, tipDurationS, releaseStartFrac, staggerS }) {
  const n = Math.max(0, Math.floor(nBalls || 0));
  const f = Math.min(1, Math.max(0, releaseStartFrac));
  const s = Math.max(0, staggerS);
  const t0 = f * tipDurationS;
  return Array.from({ length: n }, (_, i) => t0 + i * s);
}
```
