# a13: Headless Chrome hive before/after tip (red hive)

Lead: hive-visual. Worker: Haiku a13. Result: the tip worked and the red hive visibly changed between the two shots.

## What I ran
1. Static server (my own, port 8821, bound to 127.0.0.1):
   `C:/Users/Jindal/StudioProjects/MakEMinds_Sigmaz/field_sim/.venv/Scripts/python.exe -m http.server 8821 --bind 127.0.0.1` run from `field_sim/web`.
   `curl` returned HTTP 200 for `/index.html`.
2. Chrome with CDP (own instance, port 9413, profile in scratchpad):
   `"C:/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --enable-unsafe-swiftshader --use-gl=swiftshader --no-first-run --disable-gpu-sandbox --remote-debugging-port=9413 --user-data-dir=<scratchpad>/h13/profile --window-size=1280,800 about:blank`
   I used CDP instead of `--screenshot` because `--screenshot` is one-shot and cannot call `__sim.tip()` in between.
3. Driver: `<scratchpad>/h13/cdp_tip.mjs` (Node 24, global WebSocket, CDP over `/json/list`). It set the viewport to 1280x800, navigated to `http://127.0.0.1:8821/index.html`, polled until `window.__sim.hive.red` existed, waited 8 s, read state, captured `before.png`, ran `window.__sim.tip('red')`, waited 0.5 s and 4.5 s (reading state at each), and captured `after.png`.
   Command: `node cdp_tip.mjs <scratchpad>/h13` (timeout 150 s).
4. Stopped only my own processes: the listener on 8821 (PID 26372) and the Chrome processes whose command line contained `remote-debugging-port=9413` (PIDs 23520, 17204, 8944, 25160). Afterwards `curl` to 8821 returned 000 and 9413 was down.

## Visual comparison
- The red hive is visibly different between the two images. In the before shot, the red cells sit in the audience-up pose. In the after shot, the red hive cells are re-oriented (the red frame and cell outlines are at different angles and positions). The blue hive is unchanged.
- The aim/trajectory marker above the red hive also moves in the after shot (a pink outlined marker appears above the red hive). Flywheel "now" changed from 1051 to 1979 between shots (the robot's shooter spin-up, unrelated to the tip).
- Some balls in the red hive moved slightly. I did not measure this.
