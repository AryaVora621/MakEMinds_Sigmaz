Both cite G418. This affects feedFromFlower. Needs a clean manual read.
2. Manual version: FIELD_CONSTANTS.md:6 and research_manual.md:7 cite TU07. matchrules.js cites TU08 (research_manual.md:13). Flower section numbers (9.7, 10.5.2) depend on which is correct.

4. Wall distance mixes frames: FIELD_CONSTANTS.md:98 says the opening is "3.9 in inside the wall", which uses nominal 144 (144 - 140.07 = 3.93). The CAD glass inner face is 142.674 (FIELD_CONSTANTS.md:75; Java:6). From that face the opening is 2.6 in.
5. Ownership wording: research_manual.md:50 says "owns" (dynamic, by top nectar). FIELD_CONSTANTS.md:58 says "no fixed owner". These are compatible, but the code should treat ownership as dynamic.
6. Scoring volume location: flower.md:17 says "between top and middle ring". FIELD_CONSTANTS.md:17 says Layer C (top ring). No middle-ring data exists in the four files.
7. Points phase: research_manual.md:51 and 86-87 give phases from a garbled table. matchrules.js:26 says TELEOP. Not reconciled.
