## 2. How the sim loads robot models today
- `web/js/app.js` ~246-258: builds the procedural robot via `buildRobot` (robotmodel.js) from `data/robot_spec.json`, then calls `tryLoadRobotGLB(THREE, 'data/robot.glb', robotSpec, {})`.
- If the GLB loads: procedural children are hidden (`robot.children.forEach(... visible = false)`), CAD group added, flower arm kept visible (app.js line ~254). If not: HUD note "procedural placeholder".
- `web/js/robotglb.js`: own dependency-free GLB/glTF parser (no GLTFLoader vendored). Supports meshes, node transforms, PBR colours. NOT supported: textures, animations, skins, morph targets, Draco/meshopt, sparse accessors.
- `placeCAD` (robotglb.js ~238-275): auto-detects units (m/cm/mm/in) to match the 18 in footprint within 40%, centres the bbox on x=y=0, puts the lowest point at z=0, warns if any size > 18.5 in.
- `web/data/MODEL_README.md` documents the Onshape export steps (GLTF, .glb, Draco OFF, save as `web/data/robot.glb`).
- Tests: `tests_js/robotmodel.test.mjs` covers the parser and loader with synthetic GLBs only. No test uses a real robot file.

## 4. Flower hinge re-measurement (what the lead must decide)
- The loader recentres the WHOLE model's bounding box on the robot origin. So any hinge coordinate measured from the CAD origin is wrong by the bbox offset. Stray parts (tape, field pieces, hardware in an assembly export) change the offset.
- Required: export a chassis-only reference (or measure in the exported file after `placeCAD`'s recentring) and record the offset used. Do not reuse the Onshape origin.
- Hinge axis must be the lateral (y) axis at (x, z) in robot frame, +x forward, z up, floor z=0.
- Onshape exports one node per occurrence with the assembly origin; a sub-assembly's pivot is not a node origin unless a mate origin is set (MODEL_README.md "Moving parts"). Measure the hinge from the arm's pin geometry, not from the node origin.
- Arm stowed/deployed angles (flower_arm.json `angles`) come from FlowerMech.java servo positions (cad_todo item 2). Not from CAD. Keep the procedural arm for animation.
